Registration Status Guide
Pending
The submission has arrived and still needs review.
Needs Information
Information is missing or needs correction. Add a note explaining what is required.
Ready for Approval
Review is complete. This optional marker does not create anything.
Processing
A temporary system status while TMS applies tenant data and optionally creates a lease. It cannot be selected manually.
Processing Failed
The automatic transaction failed safely. Read the admin note, correct the cause, then retry the final approval action.
Approved
The final approval action applied tenant information. A lease is also created when Property and Unit were selected.
Rejected
The submission was declined and no lease will be created.
